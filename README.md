# FUTURE_FS_02 — Mini Tech E-Commerce Store

## Overview
A modern mini e-commerce frontend for tech & gadgets built as part of the
Future Interns Full Stack Web Development internship.

## Tech Stack
- React (Vite)
- Tailwind CSS v4
- Context API
- Fake API (DummyJSON)
- React Router

## Features
- Landing page for first-time users
- Product listing with search & category filter
- Product detail page
- Shopping cart with quantity control
- Checkout simulation with form validation
- Order confirmation page
- Order history (frontend)
- Authentication flow (frontend only)
- Responsive & dark UI
